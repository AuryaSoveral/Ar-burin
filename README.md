## AR Burin — Marcenaria Sob Medida

Website desenvolvido para uma marcenaria especializada em móveis planejados sob medida, com foco em design moderno, sofisticação e experiência premium.

O projeto foi criado com o objetivo de transmitir elegância, qualidade artesanal e fortalecer a presença digital da marca.

## Funcionalidades

- Layout moderno e responsivo  
- Hero section com visual impactante  
- Carrossel infinito de ambientes  
- Navegação suave entre seções  
- Botão flutuante para WhatsApp  
- Animações suaves e interativas  
- Design focado em UX/UI  
- Estrutura organizada e otimizada  

##  Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub


## Objetivo do Projeto

Criar uma experiência digital elegante e moderna para apresentar os serviços da marcenaria, destacando ambientes planejados e valorizando os detalhes dos móveis sob medida.
